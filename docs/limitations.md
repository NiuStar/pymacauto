# 能力与安全边界

## 支持范围

- macOS 公开 Accessibility API，Python 3.10+；原生实测环境为 Apple Silicon、Python 3.12、PyObjC 13。
- 目标应用必须已运行并提供 AX 控件。画布、自绘内容、未暴露的虚拟行不能凭空读取。
- 当前不提供应用启动/登录、全局键盘鼠标注入、OCR、滚动补全、AXObserver 或后台常驻服务。
- 原生权限必须由操作者授予，不修改 TCC、不绕过 SIP。

## 引用、定位与等待

从 `Application` 创建的 Locator 每次重新查询整条选择链。由 `Element` 创建的 Locator 仍绑定该原生容器引用，窗口或页面重建后必须重新取得容器。CLI 指定 `--window-identifier` 的等待每轮重新解析顶层窗口。

严格查询不能使用截断结果证明唯一；超过节点或深度预算会报错。诊断 `inspect` 允许部分结果，必须查看 `complete`、`limits_hit` 和节点错误，不能拿诊断序号当动作定位器。

轮询 timeout 不是同步 AX 调用的硬取消期限。目标应用挂起时可能先受原生 RPC 超时影响。框架默认不抢焦点，但应用可能因 AX 动作自行激活或弹窗。

## 写入与动作

`set_value` 确认的是 AXValue 相等，不保证模拟物理键盘、不证明触发了应用输入回调。`click`/`perform` 的返回只确认派发，不确认页面、订单或其他业务效果；调用者必须检查独立后置条件。歧义、超时或派发错误不能通过盲重试解决。

安全输入框的内容读写不受支持；原始 `get` 仅允许其基础结构属性。底层 backend 属于原始桥接层，不是安全沙箱。SDK 修改方法调用即执行，只有 CLI 提供 `--execute` 开关。

标签字段定位是 AX 几何启发式：同父容器、唯一精确标签、右侧同一行唯一输入框。它不等于应用原生语义关联。布局或版本改变必须重新验收。

## 表格

严格读取器只支持当前规定的 AXTable 结构：索引连续、表头唯一、双轴引用一致、AXStaticText 字符串单元格、完整双读相等。其他工具包的 AXCell 嵌套结构暂不自动适配。

`AX_EXPOSED_ROWS_ONLY` 不代表已完成翻页、筛选解除或隐藏行覆盖。零行不代表业务无记录；不同表格之间不是原子快照。

## 数据与交易

诊断元数据、普通树和表格可能包含个人信息。使用私有目录及 `--output`，不要把输出、恢复日志、截图或凭据提交到公开仓库。输出文件独占创建为0600，不保证父目录隐私，磁盘写入失败也不等于动作没发生。

可选同花顺 profile 仅针对指定版本的查询页面；不含策略、下单、撤单、资金转账、授权或自动交易闭环。字段赋值和当前持仓读取验收不能代替提交/成交结果验证。
